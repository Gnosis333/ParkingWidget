# Parking Memory Widget

This is a simple Android Widget to remember which floor you parked on (1F or 2F).

## How to use

1. Open **Android Studio**.
2. Select **Open** or **Import Project**.
3. Navigate to `d:/Android/ParkingWidget` and click OK.
4. Wait for Gradle to sync (Internet connection required).
5. Build and Run on an Emulator or Real Device.
6. Once installed, go to your home screen, long press, select **Widgets**, and find **Parking Memory**.
7. Drag the widget to your home screen.

## Features
- Updates immediately on tap.
- Remembers your selection even after rebooting (uses SharedPreferences).
- Simple, high-contrast Dark/Neon design.
